# Лабораторна робота №1 (Java)

Соловійщук Назар Олексійович, група ІО-45

Тема: робота з JDK та середовищем розробки, процес виконання Java-програм.

## Що в репозиторії

- `simple-task` - Simple Task, варіант 2: знайти слово з мінімальною кількістю різних символів
- `hard-task` - Hard Task: власний class loader, який підхоплює зміни в `TestModule.java` без перезапуску програми

## Simple Task

Програма читає рядок зі словами, розбиває його по пробільних символах і повертає
масив з першим словом, у якому найменше різних символів. Якщо рядок порожній,
повертається порожній масив.

Запуск: відкрити папку `simple-task` у IntelliJ IDEA і запустити `Main`.

## Hard Task

Програма стежить за файлом `module/TestModule.java`. Коли файл змінюється, він
перекомпілюється, завантажується новим class loader і виводиться новий результат.

Запуск: відкрити папку `hard-task` у IntelliJ IDEA і запустити `Main`
(робоча папка має бути `hard-task`, бо шляхи відносні). Не зупиняючи програму,
змінити текст у `module/TestModule.java` і зберегти файл.

## Версії

JDK: 26 (openjdk 26.0.1), IntelliJ IDEA 2026.1
